## Design contract

Source context service binds an explicitly imported, preserved public GitHub response/receipt to one observation and terminal job. It hides response identity, hash and provenance verification. Callers rely on exact source strings, immutable context identity and unavailable/error states. They do not locate research folders, fetch network data or infer formatting. A small adapter owns immutable files and SQLite metadata using existing storage conventions. This is preferable to reading study-specific folders in the web layer or rewriting dataset/model evidence.

New assessments retain the context digest shown in their form; a stale form cannot silently acquire newer context. Recorded means presented, not proof of attention. Existing decisions are not retroactively attributed context. Source quote validation remains against dataset strings. External source differences remain visible rather than being called formatting-only without checking.
