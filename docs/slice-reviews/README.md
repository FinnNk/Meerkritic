# Slice reviews

Copy [SLICE_REVIEW_TEMPLATE.yaml](SLICE_REVIEW_TEMPLATE.yaml) for each completed
slice. Record delivered behaviour, validation, deviations, architecture
before/after/delta, decisions, design review and revisions to remaining slices.
Link relevant ADRs and EDRs by identifier and short title. Link DER readiness
without copying the external DER evidence store.
